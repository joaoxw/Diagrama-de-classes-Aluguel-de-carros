# Requisitos do Sistema de Aluguel de Carros


# Requisitos Funcionais

Requisitos funcionais representam as funcionalidades que o sistema deve possuir.


## RF01 - Cadastro de clientes

O sistema deve permitir o cadastro de clientes com informações como nome, CPF, telefone e endereço.


## RF02 - Cadastro de veículos

O sistema deve permitir que funcionários cadastrem veículos disponíveis para aluguel.


## RF03 - Consulta de veículos disponíveis

O sistema deve permitir que clientes consultem veículos disponíveis para locação.


## RF04 - Realizar aluguel de veículo

O sistema deve permitir que clientes realizem o aluguel de um veículo.


## RF05 - Registrar devolução do veículo

O sistema deve permitir registrar a devolução dos veículos alugados.


## RF06 - Registrar pagamento

O sistema deve permitir registrar os pagamentos realizados pelos clientes.



---

# Requisitos Não Funcionais

Requisitos não funcionais representam características de qualidade do sistema.


## RNF01 - Segurança

O sistema deve proteger os dados pessoais dos clientes.


## RNF02 - Desempenho

O sistema deve responder às solicitações dos usuários rapidamente.


## RNF03 - Usabilidade

O sistema deve possuir uma interface simples e fácil de utilizar.


## RNF04 - Disponibilidade

O sistema deve permanecer disponível durante o funcionamento da locadora.
